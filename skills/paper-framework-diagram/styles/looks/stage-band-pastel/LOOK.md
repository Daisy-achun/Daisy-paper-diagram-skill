# Look: `stage-band-pastel`


## One-line vibe

半透明/浅灰阶段色带横贯画布；橙/薄荷绿训练胶囊；阶段间虚线分隔。

## Design thinking

```text
Paint wide translucent pastel bands for Stage-1 / Stage-2. Inside bands, place
compact train capsules (mint+fire) and light operator chips. Keep band titles
left-aligned. Use this when stages matter more than sample-card density; if
samples dominate, prefer `sample-card-reward`.
用宽半透明pastel色带标Stage；带内薄荷绿训练胶囊+小模块；阶段标题左对齐；
若样本卡更重要则改用sample-card-reward。
```

## Prompt keywords

```text
translucent pastel stage bands, mint train capsules with fire, dashed stage separators,
compact operator chips, two-tier horizontal workflow, soft academic shadow optional
半透明阶段色带, 薄荷绿训练胶囊, 虚线分隔, 两层横流
```

## Forbidden

- 色带颜色无语义随机彩虹  
- 与 `sidebar-stage` 厚虚线壳混用到看不清层级
