# Look: `sidebar-stage`


## One-line vibe

绿 / 蓝 / 橙厚虚线 Stage 壳横排；宽软过渡箭；壳内浅色实心模块；小🔥表微调。

## Design thinking

```text
Give each stage a thick dashed border in its own hue and a matching bold title.
Inside: lighter solid cards for operators. Connect stages with wide
semi-transparent chevron arrows. Keep icons sparse (clipboard, doc, fire).
If Method has vertical stage tabs on the left, place colored pills there; else
horizontal shells are enough.
每阶段独立色相厚虚线壳+同色标题；内部更浅实心模块；阶段间宽软箭头过渡；
图标克制；可选用左侧竖向Stage色签。
```

## Style keywords

```text
multi-stage pipeline, thick dashed stage shells green blue coral,
wide soft transition arrows, nested rounded operator cards, small fire fine-tune,
flat academic vector, white background, bold stage titles
多阶段彩色虚线壳, 宽过渡箭, 嵌套圆角模块, 小火焰微调
```
