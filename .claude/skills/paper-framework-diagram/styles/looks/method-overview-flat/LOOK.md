# Look: `method-overview-flat`


## One-line vibe

扁平总览：多输入汇入中央骨干（常为 LLM）；侧挂专用模块；🔥⚙❄ 三态图例；疏箭头。

## Design thinking

```text
Default when Method is a single backbone with helpers. Place the largest block
center-top (LLM). Feed image/text/tag tokens from below. Side modules
(SAM, detectors) connect with thin arrows. One legend for train states.
Avoid inventing agent loops or GRPO cards if Method has none.
单骨干+辅助模块时的默认观感；中央大块LLM；下方多路token汇入；侧挂SAM等；
三态图例一次；Method没有就不要硬造Agent环或GRPO卡。
```

## Style keywords

```text
flat method overview, central pastel LLM block, multi-token inputs,
side SAM or detector modules, fire gear snowflake legend once,
thin black arrows, handwritten-friendly sans labels optional, white canvas
扁平方法总览, 中央LLM, 多路输入, 侧挂模块, 🔥⚙❄图例
```
