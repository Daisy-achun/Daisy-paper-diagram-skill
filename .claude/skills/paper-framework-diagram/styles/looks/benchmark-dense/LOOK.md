# Look: `benchmark-dense`


## One-line vibe

(a)(b) 大面板；嵌套 QC / 标注 UI；模型 logo 墙；三色指标砖。

## Design thinking

```text
Only use when Method is about benchmark construction or multi-model evaluation
protocol. Nested rounded panels for generation, QC, human annotation, MLLM hub.
Logo wall is OK here. Metric tiles in semantic colors. Never drop AUC curves or
tables into this look — those are results, not framework.
仅当Method是基准构建/多模型评测协议时使用；嵌套圆角面板+logo墙+指标砖；
禁止塞AUC曲线和结果表。
```
