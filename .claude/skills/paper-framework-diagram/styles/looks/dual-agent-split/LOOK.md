# Look: `dual-agent-split`


## One-line vibe

顶栏 Perception / Detection 双 Agent 横流；底栏左右 zoom-in + Toolbox 色标签墙；红标题点缀；贴纸图标。

## Design thinking

```text
Top row = end-to-end story (User → Perception Agent → Detection Agent → Report).
Bottom = magnification: left Perception internals with <think>/<answer>, right
Detection + Summarizer, plus a Toolbox catalog with colored domain tabs.
Use sticker-flat colorful icons (detective, toolbox) after matting. Red bold for
agent titles only — not the whole palette.
顶栏讲完端到端故事；底栏左右放大两Agent内部与Toolbox色标签墙；贴纸风图标抠图；
红色只点缀Agent标题。
```

## Style keywords

```text
dual agent pipeline, perception yellow detection green cards, red title accents,
sticker-flat icons matted, think-answer monospace blocks, toolbox colored tabs,
hierarchical overview then zoom-in, soft gray block arrows
双Agent横轨, 感知黄检测绿, 红标题, 贴纸图标, Toolbox色标签, 总览+下探
```
